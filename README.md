# AI-driven_automated_penetration_testing_tools
Lo studio valuta sei framework agentici di penetration testing su OWASP Juice Shop con LLM locali (Qwen2.5-Coder) e cloud. Solo BugTraceAI, CAI e PentestGPT hanno rilevato vulnerabilità valide, spesso con supporto umano. Gli altri hanno fallito per errori di tool-calling, evidenziando i limiti di autonomia dei modelli compatti.
